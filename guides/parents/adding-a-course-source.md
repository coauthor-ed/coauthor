CoAuthor comes with a built-in library. A **course source** adds more: lessons, tests and simulations that someone else hosts on their own website, for example a teacher, a school, or another parent who wrote a course.

## Before you add one

> [!WARNING]
> A course source can run its own simulation code inside CoAuthor, with the same access the app has. That includes your child's saved progress on this device. **Only add a source you trust**, the way you would only install an app you trust.

Good signs that a source is safe:

- you know the person or school who runs it;
- its course files are public, for example in a public GitHub repository, so others can read them;
- the link was given to you directly, not found in an advert or a message from a stranger.

## Adding it

1. Open the **Parent area** (see [Profiles and the parent area](profiles-and-parental-gate)).
2. Go to **Settings**, then **Course sources**.
3. Paste the source's address (its manifest URL) in the box and press **Add source**. The person who made the course will give you this.
4. If a warning appears, read it, and add the source only if you trust it.

![The Course sources window in the parent area. It says no courses from other websites have been added yet, and has a box for the manifest address and an Add source button.](media/course-sources.png "Paste the address in the box, then press Add source.")

The new courses appear on the Discover page and on your child's home page.

## Removing it

In the same list, choose **Remove** next to the source. Its courses disappear from the app. Progress your child made in them stays saved on the device, in case you add the source back later.

## Bundles from a link

Sometimes a lesson link brings in a single course bundle from somewhere else. Those appear under **Bundle sources** in the same section, and **Forget** removes them.

## Writing your own course

You can write a course yourself and host it the same way. The [author guides](what-the-agent-kit-does) show how.
