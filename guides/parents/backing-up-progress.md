All progress lives only on the device, inside the browser. There is no cloud copy. A backup is a single file you keep somewhere safe, and it takes a few seconds to make.

## When to make a backup

- every few weeks, as a habit;
- before you clear the browser's data, reset the device or update the operating system;
- before you move to a new phone, tablet or computer.

## Save a backup

1. Open the **Parent area**, then **Settings**, then **Backup and restore**.
2. Under **Save a backup**, choose **Export backup**.
3. One file downloads. It holds every child's progress on this device.

![The Backup and restore window, in the dark theme: Save a backup with an Export backup button, and Restore a backup with an Import backup button.](media/backup-dialog.png "Export backup saves the file. Import backup restores one.")

Keep the file somewhere other than the device itself: a USB stick, your email, or a cloud drive.

> [!NOTE]
> The file contains your children's names and their learning history. Treat it like any other private family document.

## Restore a backup

1. Open **Backup and restore** on the device you want to restore to.
2. Under **Restore a backup**, choose **Import backup** and pick the file.
3. If this device already has progress, CoAuthor first downloads a safety copy of it, then asks before it overwrites anything.

## Moving to a new device

1. On the old device, save a backup.
2. On the new device, open CoAuthor in the browser your child will use, and set up a profile.
3. Restore the backup there.

If you had added course sources, CoAuthor offers to restore those too.

> [!WARNING]
> Use the same browser every time. Chrome and Firefox on the same computer keep separate copies of the app and its progress.
